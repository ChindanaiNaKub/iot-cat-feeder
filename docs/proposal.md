# ข้อเสนอโครงการ เครื่องให้อาหารแมวอัตโนมัติ

สถานะเอกสาร: ฉบับร่าง 0.9 · 30 ตุลาคม 2569
กำหนดส่ง: 4 พฤศจิกายน 2569

## 1. ปัญหา

แมวส่วนใหญ่กินอาหารไม่ตรงเวลาเพราะเจ้าของเป็นคนตวงและเทอาหารเอง อาหารอาจเหลือค้างในจานตลอดวันหรือหมดก่อนเวลา เจ้าของที่ต้องออกจากบ้านทั้งวันทำได้แค่เทอาหารกองใหญ่ไว้ ซึ่งทำให้แมวกินเกินและเสี่ยงอ้วน

## 2. เป้าหมาย

สร้างเครื่องให้อาหารที่ตวงอาหารเป็นมื้อตามเวลาที่กำหนด และให้เจ้าของสั่งอาหารเพิ่มได้จากมือถือโดยไม่ต้องเดินไปที่เครื่อง

## 3. วัตถุประสงค์

1. ให้อาหารอัตโนมัติ 3 เวลาต่อวัน โดยดึงเวลาจริงจาก NTP ไม่ใช่นับถอยหลังบนบอร์ด
2. สั่งให้อาหารทันทีได้จากหน้าเว็บใน Wi-Fi วงเดียวกัน
3. ปิดฝาอัตโนมัติทุกครั้งเพื่อไม่ให้อาหารไหลออกเกินหนึ่งมื้อ
4. บันทึกจำนวนครั้งและเวลาที่ให้อาหารแล้ว แสดงบนหน้าเว็บ

## 4. ขอบเขต

อยู่ในขอบเขต

- ควบคุมฝาด้วย servo และหน้าเว็บที่บอร์ดให้บริการเอง
- ตั้งเวลาให้อาหารด้วย NTP
- ประวัติการให้อาหารในหน่วยความจำ พร้อมแสดงบนหน้าเว็บ
- ตรวจการเข้ามาใกล้ของแมวด้วย ultrasonic และโหมดให้อาหารอัตโนมัติเมื่อแมวมา
- วัดระดับอาหารในถังด้วย ultrasonic

นอกขอบเขต

- ตวงน้ำหนักอาหารต่อมื้อด้วย load cell และ HX711 เลื่อนเป็น Future Work เพราะยังไม่ได้บัดกรีขาโมดูล โค้ดทดสอบและผังต่อสายเตรียมไว้แล้ว
- กล้องวงจรปิดและเสียงสองทาง
- แอปมือถือแยกต่างหาก และ cloud database
- การยืนยันตัวตนผู้ใช้ เพราะเครื่องทำงานใน Wi-Fi วงเดียวกัน
- ควบคุมอาหารหลายถังหรือหลายแมว

## 5. ผู้ใช้และสถานการณ์ใช้งาน

**เจ้าของแมวที่ทำงานนอกบ้าน** ตั้งเวลาไว้ 3 มื้อ แล้วเปิดหน้าเว็บดูตอนกลางวันว่าแมวกินไปกี่ครั้ง ถ้าอาหารหมดก่อนเวลา เขาเทอาหารเพิ่มที่ถัง

**แมว** เดินเข้ามาที่เครื่องช่วงเวลาที่ใกล้มื้ออาหาร เซ็นเซอร์จับได้แล้วเครื่องตวงอาหารหนึ่งมื้อให้

## 6. เกณฑ์ความสำเร็จ

| ข้อ | เกณฑ์ | วิธีวัด |
|---|---|---|
| 1 | ให้อาหารตรงเวลาที่ตั้งไว้ 3 เวลาต่อวัน | ทดสอบกับเวลาจริง 24 ชั่วโมง บันทึกเวลาในหน้าเว็บ |
| 2 | คำสั่งจากหน้าเว็บทำงานภายใน 1.5 วินาที | กดปุ่มแล้วจับเวลาฝาเปิด |
| 3 | ฝาปิดกลับเองทุกครั้ง | ทดสอบ 50 รอบ ไม่มีรอบใดค้างเปิด |
| 4 | ประวัติตรงกับที่เกิดขึ้นจริง | เทียบกับบันทึกเวลาที่จดไว้ระหว่างทดสอบ |
| 5 | ตรวจแมวในระยะ 60 เซนติเมตรได้ | ทดสอบกับแมวจริง 20 ครั้ง |

## 10. ความเสี่ยง

| ความเสี่ยง | ผลกระทบ | การรับมือ |
|---|---|---|
| Servo ดึงกระแสจนบอร์ดรีบูต | เครื่องรีสตาร์ทกลางมื้อ | จ่ายไฟ servo จาก powerbank ผ่าน VIN และใส่ capacitor 470 µF |
| ค่า ultrasonic สั่นเพราะผิวอาหารไม่เรียบ | อ่านระดับผิด | สุ่ม 10 ครั้งแล้วใช้ค่ามัธยฐาน |
| Calibrate load cell ไม่ทัน | ไม่ได้ข้อมูลน้ำหนัก | เกิดขึ้นจริง ตัดออกจาก v1 และย้ายไป Future Work ตามแผน |
| Wi-Fi ในห้องสอบบล็อกพอร์ต | สาธิตผ่าน cloud ไม่ได้ | ใช้ HTTP ในวง LAN เป็นช่องทางหลัก |
