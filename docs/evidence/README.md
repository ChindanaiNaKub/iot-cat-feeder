# หลักฐานที่ต้องเก็บ

ใช้สำหรับหัวข้อ Output & Discussion และ Photos & Evidence ใน rubric

## ข้อควรยึด

- ถ่ายในที่แสงพอ ไม่ใช้แฟลชตรง เพราะเงาจะทับรายละเอียดสายไฟ
- ให้เห็นบริบท ไม่ใช่ครอปจนเหลือแต่ของ
- ห้ามมีสายโน้ตบุ๊กในภาพที่อ้างว่าใช้ powerbank
- เก็บไฟล์ต้นฉบับ ไม่ต้องแต่งภาพ
- ตั้งชื่อไฟล์ให้เรียงตามลำดับ เช่น `01_device_wide.jpg`

## ภาพที่ควรมี

ไม่ใช่โควตา ขาดข้อไหนได้ถ้าภาพที่มีอยู่ยังพิสูจน์ rubric ข้อ Photos & Evidence ได้

| # | ภาพ | พิสูจน์อะไร |
|---|---|---|
| 01 | เครื่องทั้งเครื่องมุมกว้าง เห็นถัง ฝา ถ้วย และบอร์ด | ภาพรวมของสิ่งประดิษฐ์ |
| 02 | เบรดบอร์ดและสายไฟ มองจากด้านบน | คุณภาพการต่อวงจร |
| 03 | จุดยึด servo กับก้านโยงและฝา | งานเชิงกล |
| 04 | capacitor 470 µF ที่ขั้ว servo | การแก้ปัญหาไฟตก |
| 05 | powerbank ที่ต่ออยู่กับบอร์ด ไม่มีสายโน้ตบุ๊ก | ทำงานได้โดยไม่พึ่งคอมพิวเตอร์ |
| 06 | จุดติดตั้งเซ็นเซอร์วัดระดับอาหารบนถัง | ตำแหน่งเซ็นเซอร์และงานยึด |
| 07 | หน้าจอมือถือที่เปิดหน้าเว็บ แสดงเวลาบนเครื่องและจำนวนมื้อ | ส่วนต่อประสานกับผู้ใช้ |
| 08 | ฝาเปิดและอาหารกำลังตกลงถ้วย | การทำงานจริง ไม่ใช่ของนิ่ง |
| 09 | อาหารที่ตกลงในถ้วย | ผลลัพธ์ที่จับต้องได้ |
| 10 | Serial Monitor ที่เห็น IP และบรรทัดสถานะ | เฟิร์มแวร์รันอยู่จริง |
