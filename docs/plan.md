# แผนโปรเจกต์ IoT Cat Feeder

กำหนดส่ง: 4 พฤศจิกายน 2569

## เป้าหมาย

เครื่องให้อาหารแมวแห้งอัตโนมัติ ควบคุมและดูสถานะผ่านหน้าเว็บในวง Wi-Fi เดียวกัน ทำด้วย NodeMCU v3 (ESP8266) และ servo SG90

## ขอบเขต v1 (ที่ต้องส่ง)

1. ควบคุมเปิด/ปิดผ่านหน้าเว็บ (ทำแล้ว)
2. ทดสอบ servo เปิด/ปิดฝา
3. ตั้งเวลาให้อาหารได้ 2–3 เวลาต่อวัน โดยดึงเวลาจาก NTP
4. บันทึกประวัติการให้อาหาร (เวลาล่าสุดและจำนวนครั้งต่อวัน) และแสดงในหน้าเว็บ

นอกขอบเขต v1: กล้อง เสียง และเซ็นเซอร์วัดอาหาร จะเป็นงานในอนาคต

## อุปกรณ์

| รายการ | สถานะ |
|---|---|
| NodeMCU v3 | มีแล้ว |
| Breadboard, LED, ตัวต้านทาน 220 Ω | มีแล้ว |
| สาย micro USB | ซื้อแล้ว |
| Servo SG90 | ต้องซื้อ |
| Capacitor 470 µF 16V | ต้องซื้อ |
| Powerbank 5V 2A ขึ้นไป | ต้องตรวจว่ามีหรือไม่ |
| ถังอาหารแห้งและกระดาษแข็งทำฝา | ใช้ของที่มี |

ผังการต่อดูได้ที่ `docs/wiring_nodemcu_servo.html`

## ลำดับงาน

1. ซื้อ servo และ capacitor แล้วทดสอบ servo ตามโค้ดทดสอบ
2. ต่อ servo กับถังอาหารและทดสอบการเปิดปิดฝา
3. เขียนโค้ดตั้งเวลาให้อาหารและทดสอบกับเวลาจริง
4. เพิ่มประวัติการให้อาหารในหน้าเว็บ
5. ทดสอบรวมกับแมวจริงและถ่ายรูป/วิดีโอเป็นหลักฐาน
6. เขียน SRS, SDD, Proposal, Output และ Conclusion

## ความเสี่ยง

- servo ค้างเปิดฝาถ้าข้อผิดพลาดเกิดขึ้น ต้องกำหนดเวลาปิดกลับในโค้ดเสมอ
- Wi-Fi จากมือถือต้องเป็น 2.4 GHz และเปิด Maximize Compatibility
- ไฟจาก powerbank ต้องชาร์จเต็มก่อนวันนำเสนอ
- รหัส Wi-Fi อยู่ในโค้ด ห้าม commit รหัสจริง

## v2 (ทำถ้ามีเวลาและงบ)

- กล้องวงจรปิดด้วย ESP32-CAM
- เสียงสองทางด้วยไมค์และลำโพง I2S
- เซ็นเซอร์วัดระดับอาหาร
- จอ LCD หรือ OLED แสดงสถานะ

## การเทียบกับ rubric

- Concept & Problem Fit และ UX: ปัญหาแมวกินอาหารไม่ตรงเวลาที่เจ้าของเป็นคนเลี้ยง
- Hardware: การต่อ servo กับ powerbank และ capacitor กันไฟตก
- Software: การตั้งเวลา NTP และการบันทึกประวัติ
- IoT Integration: HTTP บน ESP8266 ควบคุมและดูสถานะจากเว็บ
- Doc: docs ใน repo นี้ และ Future Work จากหัวข้อ v2
